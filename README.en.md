# User growth dashboard for an edtech (SQL + Metabase)

A Metabase dashboard built on SQL queries to understand an edtech's leads and define actions to grow the number of registered users.

![Dashboard](DashBoard%20Edtech/Dashboard%20Edtech.png)

## Problem

The edtech wanted to grow sign-ups, but didn't know who its leads were, how they consumed content, or which platform they responded to best.

## Solution

Five SQL queries on the leads tables, each turned into a Metabase chart and combined into a single dashboard:

| Question | Visualization |
|---|---|
| How many leads are men and how many are women? | pie |
| What is the average age of leads? | card |
| How many leads are there per education level? | bars |
| What is the average watched content per language (only for those who watched more than 50%)? | table |
| How many calls were answered per platform? | line |

## Result

- A dashboard with the lead profile and engagement by language and platform. Screenshots are in the `Consultas SQL` folder.
- A presentation with action plans derived from the analysis (`DNC_Desafio 3 - GS.pdf`).
- A challenge from the DNC Data Scientist program, completed with a perfect score.
